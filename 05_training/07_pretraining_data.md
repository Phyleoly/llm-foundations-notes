# 预训练语料与数据组织

> 状态：提纲

> 前置内容：[Tokenizer 的完整处理流程](../03_tokenization/04_tokenizer_pipeline.md)。

本篇要回答：语料经过哪些处理后才成为语言模型的训练输入？

## 1. 数据来源与划分

- 记录领域、语种、时间范围与数据来源，先明确训练、验证和测试边界。
- 说明文档、段落和近重复内容跨划分时会造成什么评估问题。

## 2. 清洗、去重与混合

- 分别列出质量过滤、精确去重、近重复处理与采样配比的目标。
- 记录处理前后的文档数与 token 数，区分经验规则与已经验证的效果。

## 3. Tokenization 与序列构造

- 固定 tokenizer 版本与文档边界约定，描述编码、分片和读取过程。
- 将 packing 和 loss mask 的具体处理链接到 batching 笔记。

## 4. 最小数据审计

- 抽取少量样本检查文本、token IDs、边界标记和目标对齐。
- 记录验证集隔离、数据版本、采样种子与处理统计，支撑后续复现。
