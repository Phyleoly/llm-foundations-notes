# 学习率调度与训练预算

> 状态：提纲

> 前置内容：[梯度优化、AdamW 与梯度裁剪](./02_optimization.md)。

本篇要回答：学习率应随哪种训练进度变化，怎样记录才便于比较实验？

## 1. 训练进度的单位

- 区分 micro-step、optimizer step、epoch 与已处理 token 数。
- 说明 batch size 和梯度累积变化时，相同步数为什么可能代表不同训练量。

## 2. Warm-up 与衰减

- 分别写出 warm-up、恒定学习率、线性衰减和 cosine decay 的分段定义。
- 明确峰值、最低值、总更新次数与调度器调用位置。

## 3. 预算与比较口径

- 记录训练 token 预算、模型规模、数据配比与优化器更新次数。
- 区分固定数据量、固定步数和固定计算预算的比较，不直接套用未经核对的 scaling 结论。

## 4. 最小例子与续训

- 绘制一条短训练过程的学习率曲线，标注边界点。
- 说明 checkpoint 恢复时如何延续进度，检查首步和最后一步的偏移。
