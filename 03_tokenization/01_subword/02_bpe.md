# 2. BPE

> 从小单元开始，每轮合并出现最频繁的相邻单元。

## 训练

简化流程：

1. 把词拆成初始符号；
2. 统计所有相邻符号对；
3. 找到频率最高的一对；
4. 合并成新 token；
5. 更新统计，继续合并；
6. 达到目标词表大小后停止。

最简单的选择规则：

```math
(a^*,b^*)=\arg\max_{(a,b)}c(a,b),
```

其中 $c(a,b)$ 是相邻对 $(a,b)$ 的出现次数。

训练后要保存：

- 初始词表；
- merge rules；
- merge rules 的顺序。

只保存最终字符串不够，因为合并顺序会影响编码结果。

## 小例子

语料：

```text
low      × 5
lower    × 2
newest   × 6
widest   × 3
```

如果 `e + s` 是当前最高频相邻对：

```text
e + s → es
```

下一轮可能继续得到：

```text
es + t → est
```

不断合并后，`low`、`er`、`est` 之类的片段可能进入词表。

实际结果还会受到这些因素影响：

- 词频；
- 词边界标记；
- 预切分方式；
- 同频候选的处理规则。

## 编码

编码时按照训练得到的 merge rank 应用规则：

1. 转成初始符号；
2. 找当前能用的 merge rule；
3. 优先应用排名更高的规则；
4. 没有规则可用时停止。

BPE 不是单纯的“每次找最长字符串”。它依赖训练时得到的规则顺序。

## 记住

优点：

- 思路直观；
- 容易实现；
- 词表大小容易控制。

问题：

- 只看局部相邻频率；
- 前面的贪心合并会影响后面；
- 预切分和字符回退策略很重要。

## 代码以后补

预留接口：

```python
model = train(corpus, vocab_size)
tokens = encode(text, model)
text = decode(tokens, model)
```

测试重点：相邻对计数、同频规则、合并顺序、未知字符和 round trip。
