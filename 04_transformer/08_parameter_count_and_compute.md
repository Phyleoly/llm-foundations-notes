# 参数量、计算量与显存

> 状态：提纲

> 前置内容：[Decoder-only Transformer 的完整前向过程](./07_decoder_only_transformer.md)。

本篇要回答：改变词表、层数、宽度、头数或序列长度，会增加哪些成本？

## 1. 参数量分解

- 分别统计 embedding、attention、MLP、归一化与输出投影的参数。
- 明确 bias、weight tying 与 GQA 的计数口径，再给出总量表达。

## 2. 前向计算量

- 从矩阵乘法形状估算投影、attention 和 MLP 的运算量。
- 区分序列长度与模型宽度的影响，写清 FLOP 计数约定。

## 3. 训练与推理显存

- 区分参数、梯度、优化器状态、激活与 KV cache。
- 对比 dtype、batch size、序列长度对各部分显存的作用，避免只算模型权重。

## 4. 最小估算与核对

- 选择一组小模型配置，完成一张参数、计算与显存表。
- 将估算与实际测量区分；记录峰值、框架开销和未计入的部分。
