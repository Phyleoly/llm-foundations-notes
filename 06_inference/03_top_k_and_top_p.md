# Top-k 与 Top-p 采样

> 状态：提纲

> 前置内容：[Temperature 与概率分布](./02_temperature.md)。

本篇要回答：如何在完整词表分布中构造一个较小的采样集合？

## 1. Top-k

- 定义按概率排名保留候选的规则，并说明截断后的归一化。
- 讨论 k、词表大小与并列概率的处理约定。

## 2. Top-p / Nucleus Sampling

- 给出排序后的累积概率与保留集合，说明越过阈值的 token 如何处理。
- 用同一 p 对比尖锐分布与平坦分布下的候选数量。

## 3. 处理顺序与组合

- 明确 temperature、top-k、top-p 的应用顺序，并记录所用实现。
- 讨论最少候选数、非法参数和其他 logits 处理规则的交互。

## 4. 最小例子与边界

- 用五个 token 手算两种截断与最终采样概率。
- 区分多样性、质量与可复现性，避免把某个参数固定描述为最优配置。
