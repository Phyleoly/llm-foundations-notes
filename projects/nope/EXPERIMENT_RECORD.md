# 实验记录模板

复制本模板后填写实际信息；没有执行的项目标为“未执行”，不把预期现象写成实验结果。

## 问题与范围

- 要检验的问题：
- 对应论文章节、公式或图表：
- 类型：基础算子检查 / 简化机制验证 / 缩小规模复现 / 原设置复现。
- 与原文设置的差异和已知限制：

## 代码与配置

- 可获取的代码 commit：
- 是否含未提交修改；如有，源码快照或哈希：
- 模型、输入、mask、初始化及统计位置：
- 随机种子、精度、训练或测量预算：

## 环境与输入

- Python、PyTorch 和其他依赖版本：
- 操作系统、设备和实际计算 dtype：
- 数据来源、版本或内容哈希；合成输入则记录生成方式：
- 环境安装命令：

## 执行与产物

- 工作目录与完整运行命令：
- 运行时间及完成状态：
- 原始数据、日志、图表与生成脚本的位置：
- Git 外部产物的获取方式和完整性标识：

## 结果与解释

- 实际测量值与对照：
- 数值误差口径和随机性检查：
- 哪些结论得到支持，哪些问题仍未验证：
- 与原文或既有结果不一致之处：
