# 评估的局限、污染与结论边界

> 状态：提纲

> 前置内容：[Perplexity 与语言建模评估](./01_perplexity.md)、[任务评估与实验协议](./02_task_evaluation.md)、[Benchmark 的覆盖范围与选择](./03_benchmarks.md)、[预训练语料与数据组织](../05_training/07_pretraining_data.md)。

本篇要回答：哪些因素会让看似清晰的评估分数支持不了预期结论？

## 1. 数据污染与选择偏差

- 区分训练测试重叠、近重复、反复调参和基准选择造成的偏差。
- 记录能够检查的证据及无法确认的部分，避免把未知训练数据当作已排除污染。

## 2. 协议敏感性与分布变化

- 检查 prompt、示例顺序、答案抽取和生成参数变化对分数的影响。
- 分别考察领域、语言、长度和时间分布变化，不将单一测试集表现直接外推。

## 3. 评分器与不确定性

- 区分自动规则、人工评判与模型评分器，并记录各自的误差来源。
- 讨论样本量、置信区间和多次比较，明确结论的测量条件。

## 4. 最小稳健性分析

- 为一个已有任务做模板变化、错误归类和分组统计。
- 写一段与证据对应的结论，分别注明已测范围、未测范围和可能解释。
