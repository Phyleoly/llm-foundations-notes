# 任务评估与实验协议

> 状态：提纲

> 前置内容：[自回归生成的完整流程](../06_inference/01_autoregressive_generation.md)、[Greedy Decoding 与 Beam Search](../06_inference/04_greedy_and_beam_search.md)。

本篇要回答：一个任务分数如何从模型输出产生，并且可以被别人复核？

## 1. 任务与预测方式

- 区分候选答案似然打分与自由生成，明确模型需要输出什么。
- 固定 zero-shot / few-shot 设置、示例来源、顺序和 prompt 模板。

## 2. 答案处理与指标

- 分别记录答案抽取、规范化、无效输出和多答案匹配规则。
- 根据任务选择 accuracy、exact match、F1 或其他指标，并说明聚合方式。

## 3. 随机性与比较

- 固定解码配置和评估样本，记录随机种子、重复次数和失败样本。
- 说明样本级不确定性与运行随机性，设计配对比较或重采样的报告方式。

## 4. 最小评估记录

- 保存少量样本的原始输入、原始输出、解析结果、得分与错误类别。
- 形成模型、tokenizer、数据、模板、代码版本和参数的完整记录表。
